# Jayesh Jadhav

**Experimental physicist · Quantum hardware & thin-film materials · IIT Bombay**

I am a **Junior Research Fellow at IIT Bombay** working on indium micro-bump interconnects and flip-chip integration for superconducting quantum-device hardware. My earlier work spans transparent conducting multilayers for solar cells and high-pressure spectroscopy.
